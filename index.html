Privacy Policy

Application: gog personal CLI (personal-use command line tool). Last updated: 11 October 2026.

This application is a private, single-user command line tool that lets its owner work with their own Google account (Gmail, Calendar, Drive, Sheets, Docs, Tasks, Contacts) from a terminal. It is used only by its owner, on his own computer, for his own data.

What data is accessed

  • Only the Google account that the owner explicitly authorises when signing in.
  • Only the services the owner grants during authorisation (for example Gmail, Calendar, Drive, Sheets, Tasks, Contacts).

How data is used

  • Data is read, and where the owner asks, created or modified — solely for the owner's own use.
  • No data is sold, rented, shared, published or transferred to any third party.
  • No advertising, profiling or analytics of personal data takes place.

Where data is stored

  • OAuth credentials are stored locally on the owner's computer, in an encrypted keyring or a local configuration file, protected by the operating system's user permissions.
  • No copies of Google account data are hosted on any server operated by the application.
  • There is no backend service: the tool runs locally and speaks directly to Google's APIs.

Data retention and deletion

  • Authorization can be revoked at any time at myaccount.google.com/permissions.
  • Deleting the local credential file removes the application's access from the device.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used only to provide and improve the owner-facing features described above, is never transferred to others except as required by law, and is never used for advertising.
